# 19. AI Usage Disclosure

Generative AI tools were used as assistants for brainstorming, documentation refinement, code debugging, UI ideation, and technical explanations.

All dataset choices, preprocessing, methodology, validation, interpretation, application logic, and final implementation are reviewed and validated by the project team.

Generative AI output is not treated as statistical evidence. Numeric results shown in Cropmatics come from documented data sources, validated models, optimization routines, or explicit application rules.
