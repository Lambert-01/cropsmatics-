# 13. Deployment

Recommended MVP:
- Web: Vercel
- API: Render or Fly.io
- DB: Neon/Supabase PostgreSQL + PostGIS
- Mobile: Expo EAS preview/internal build
- Monitoring: Sentry + structured logs

Environments:
- local
- staging
- production

Use HTTPS, backups, least privilege, migrations, health checks and rate limits.
