# 1. Project Overview

## Name
**Cropmatics Rwanda**

**Short name:** Cropmatics

**Tagline:** Crop Intelligence from Data to Action

## Positioning
Cropmatics Rwanda is an agricultural informatics and decision-intelligence platform
that combines agricultural statistics, machine learning, geospatial intelligence and
optimization to identify productivity gaps, explain associated factors, prioritize
interventions, predict post-harvest risks and improve storage, aggregation and market
coordination.

## Value proposition
A data-to-action platform that turns Rwanda agricultural statistics and verified operational signals into productivity-gap intelligence, intervention priorities, post-harvest warnings, and storage/aggregation decisions.

## Users
- Farmers
- Cooperatives
- Field/extension officers
- Storage/collection managers
- District agricultural planners
- National analysts

## Core workflow

```text
NISR/public data
  → clean/harmonize
  → crop × district × season productivity analysis
  → explain associated factors
  → intervention priority
  → farmer/cooperative harvest registration
  → post-harvest risk
  → storage/aggregation optimization
  → recommendation/alert
  → planner feedback
  → outcome capture
```

## MVP non-goals
Do not add blockchain, payments, loan underwriting, nationwide e-commerce, IoT hardware, or image-based disease diagnosis before the core workflow works.
