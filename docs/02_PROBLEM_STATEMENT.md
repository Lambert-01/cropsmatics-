# 2. Problem Statement

Rwanda has rich agricultural statistics, but raw data do not automatically tell planners where productivity gaps are greatest, which measured factors are associated with those gaps, where limited interventions should be investigated first, or how upcoming harvests should be coordinated with storage and aggregation.

## Research questions
1. Which crop–district–season combinations show the largest productivity gaps?
2. Which observed factors are associated with underperformance?
3. Where should limited interventions be prioritized for verification/support?
4. Where are upcoming harvest volumes likely to create post-harvest pressure?
5. How can available storage/collection capacity be allocated efficiently?
6. Do later operational outcomes support or contradict the recommendations?

## Language rules
Use:
- associated with
- predicts
- model contribution
- priority for investigation
- scenario estimate

Avoid unsupported statements such as:
- "fertilizer causes X% more yield"
- "this intervention will definitely raise production"
